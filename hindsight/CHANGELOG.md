# Changelog

## 1.1.0 (2026-10-22)

- Initial release of Hindsight add-on
- Upstream version 1.1.0 from vectorize-io/hindsight
- Agent memory system that replaces RAG and Knowledge Graphs with state-of-the-art accuracy
- Control Plane Web UI accessible via Home Assistant Ingress
- Dataplane API exposed on port 8888 for external agents and client SDKs
- Embedded pg0 (PostgreSQL) persistent storage mapped to Home Assistant add-on config directory
- Multi-architecture support for amd64 and aarch64
